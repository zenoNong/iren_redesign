<h4>Aura</h4>
<p>An open, self-hostable platform for human evaluation of natural language generation, built for under-resourced languages. It runs five evaluation protocols in one place (Likert/direct assessment, pairwise, ranking, error-span and post-editing), records script and speaker provenance, works fully offline, and can offer annotators an LLM assistant whose effect is logged.</p>
