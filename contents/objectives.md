#### Aim

To serve under-resourced languages with language technology that works as well for them, and for every script they are written in, as it does for high-resource languages, and to measure honestly whether it does.

#### Objectives

1. **Build for every language and script.** Develop translation and other language technology that produces well-formed output for under-resourced languages in each of their writing systems, even when authentic data is scarce.
2. **Evaluate with the right instrument.** Establish which automatic metrics and LLM judges can be trusted for which languages and scripts, rather than assuming that measures built for high-resource languages carry over.
3. **Put human judgement in speakers' hands.** Provide open, self-hostable human evaluation tools that record language, script and speaker provenance, run offline, and respect community data governance.
4. **Release openly.** Publish code, data and evaluation results so that other researchers and language communities can reuse and extend the work.
