Interdisciplinary Research for Emerging Natural-languages

We bring linguists, computer scientists and language communities together to build data, tools and models for languages that today’s technology leaves behind.

About ɪreːn

ɪreːn 🌊 (Interdisciplinary Research on Ethical & Equitable NLP for under-resourced Languages) is a research collaboration dedicated to serving under-resourced languages: languages with little parallel data, few speakers available for paid annotation, writing systems that mainstream models do not cover, and communities whose data deserves careful governance.

We build and evaluate language technology for these languages, study how such systems should be measured, and create open tools that let speakers judge the output themselves. Our work so far includes translation and evaluation for Indic languages such as Manipuri (Meiteilon), written in both Bengali and Meitei Mayek script, and we welcome work on any under-resourced language.

ɪreːn brings together researchers from Indian Central Universities, IITs, IIITs and NITs, along with international labs/institutions worldwide.

Aim and objectives

Aim

To serve under-resourced languages with language technology that works as well for them, and for every script they are written in, as it does for high-resource languages, and to measure honestly whether it does.

Objectives

  1. 01

    Build for every language and script.

    Develop translation and other language technology that produces well-formed output for under-resourced languages in each of their writing systems, even when authentic data is scarce.

  2. 02

    Evaluate with the right instrument.

    Establish which automatic metrics and LLM judges can be trusted for which languages and scripts, rather than assuming that measures built for high-resource languages carry over.

  3. 03

    Put human judgement in speakers' hands.

    Provide open, self-hostable human evaluation tools that record language, script and speaker provenance, run offline, and respect community data governance.

  4. 04

    Release openly.

    Publish code, data and evaluation results so that other researchers and language communities can reuse and extend the work.
